# Task 06 – Introduction to Cryptography

## 📌 Objective
The objective of this task is to understand fundamental cryptographic concepts through both theoretical study and practical implementation using OpenSSL on Kali Linux.

## 📘 Contents
- Introduction to Cryptography
- Symmetric Encryption using AES
- Asymmetric Encryption using RSA
- Hashing and Integrity Verification (SHA-256)
- Digital Signatures
- Comparison of Cryptographic Algorithms
- Real-World Applications of Cryptography

## 🛠️ Tools Used
- Kali Linux
- OpenSSL
- SHA-256
- RSA & AES Algorithms

## 📂 Repository Structure
- `Report/` – Contains the final PDF report
- `Screenshots/` – Practical screenshots for AES, RSA, hashing, and digital signatures
